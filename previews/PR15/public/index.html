L2ODLL.dual_completion — Function
dual_completion(model::JuMP.Model, y_predicted, param_value) -> (y, z, w)

Project the predicted y onto its dual cone and complete the remaining dual variables, returning a NamedTuple:

  • y: projected predictions, one vector per constraint in get_y;
  • z: completed dual variables, one vector per constraint in get_z;
  • w: quadratic slack variables of the dual (empty for affine objectives).

Signs follow JuMP.dual. Guarantee (Theorem 1 of Tanneau and Van Hentenryck, 2024): when the decomposition's completion is feasible, (y, z, w) is dual feasible, so dual_objective is a valid bound on the optimal value.

Decompositions

L2ODLL.AbstractDecomposition — Type
AbstractDecomposition

Supertype of DLL decompositions: which primal constraints have their dual variables predicted (y_ref) and which are completed (z). A subtype must have the fields p_ref (parameters) and y_ref (predicted constraints), implement can_decompose for auto-detection, and either have a z_ref field or implement completed_constraints. See the package guide on custom decompositions.

source

Closed-form completion (y_pred, param_value) -> (y, z, w) for the bounded decomposition: y is the projected prediction, z = [[zl_1], …, [zl_n], [zu_1], …, [zu_n]] are the bound duals (in the order of completed_constraints) and w is empty.

Closed-form DLL layer (y_pred, param_value) -> dual objective for a strictly convex quadratic objective (Example 3 of Tanneau and Van Hentenryck, 2024). See convex_qp_completion_builder for the completed dual variables.

L2ODLL.convex_qp_completion_builder — Function
convex_qp_completion_builder(decomposition::ConvexQP, proj_fn, dual_model; backend=nothing)

Closed-form completion (y_pred, param_value) -> (y, z, w): y is the projected prediction (all constraints are predicted, so z is empty) and w are the quadratic slack variables of the dual, obtained by solving the dual stationarity equations for w given y.

L2OCore interface

Defined in the package extension L2ODLLL2OCoreExt (load with import L2OCore).

L2ODLL.DLLMethod — Function
DLLMethod(; decomposition = nothing, optimizer = nothing)

Dual Lagrangian Learning as a method of the LearningToOptimize L2OCore interface (an L2OCore.AbstractDualMethod with guarantee L2OCore.ValidDualBound). Available after import L2OCore (package extension).

  • decomposition: nothing to auto-detect (as in decompose!), or a function model -> AbstractDecomposition, e.g. L2ODLL.BoundDecomposition.
  • optimizer: used when the decomposition has no closed-form completion.
import L2OCore, L2ODLL
pipe = L2OCore.L2OPipeline(L2OCore.ParametricProblem(model), L2ODLL.DLLMethod())
pred = L2OCore.complete(pipe, P, Y)        # completed duals, dual_layout order
L2OCore.check(L2OCore.ValidDualBound(), pipe.problem, P, pred; reference = opt)
source
L2ODLLL2OCoreExt.DLLDecomposition — Type
DLLDecomposition <: L2OCore.AbstractDecomposition

The L2OCore view of an L2ODLL.DLLCache: the proxy predicts the flattened y (output_dimension = sum(L2ODLL.y_shape(model)) rows) and the completion fills the remaining duals. perm maps the stacked vector [flatten_y(y); flatten_y(z)] to L2OCore's dual_layout order.

source
L2ODLLL2OCoreExt.DualLagrangianLearning — Type
DualLagrangianLearning(decomposition, optimizer) <: L2OCore.AbstractDualMethod

Dual Lagrangian Learning (Tanneau and Van Hentenryck, 2024). Construct it with L2ODLL.DLLMethod.

source
L2OCore.complete — Method
complete(::DualLagrangianLearning, pipe, inputs, output) -> Prediction

Project each predicted y onto its dual cone and complete the remaining duals (closed form for BoundDecomposition / ConvexQP, a solver otherwise). The returned dual is num_duals × B in dual_layout order with JuMP.dual signs.

Guarantee ValidDualBound (Theorems 1-2 of Tanneau and Van Hentenryck, 2024): the completed point is dual feasible, so its Lagrangian value bounds the optimum.

source
L2OCore.generate_data — Method
generate_data(::DualLagrangianLearning, pipe; sampler, n, rng, optimizer = nothing, kwargs...)

DLL is self-supervised: without optimizer the dataset holds only the sampled inputs. With optimizer, every instance is solved and the optimal objective values and duals are recorded (useful as reference for checking ValidDualBound and for reporting gaps).

source
L2OCore.loss — Method
loss(::DualLagrangianLearning, pipe, inputs, output; kwargs...) -> Real

Self-supervised DLL loss, eq. (27a) of Tanneau and Van Hentenryck (2024): the mean dual objective of the completed predictions, negated for minimization problems so that the loss is always minimized. Needs no labels.
